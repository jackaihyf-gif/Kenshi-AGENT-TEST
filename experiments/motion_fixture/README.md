# 非战斗移动夹具检查

这是纯离线验证器，不控制游戏，也不替代原有身份、暂停、存档或原生门禁。移动灯试验实际混入战斗与弹药消耗，因此将未知状态、战斗、伤病及弹药数量/电量变化视为夹具无效。

调用者先通过已有受限接口验证单一角色及会话，取得基线ammo_signature，随后每个采样立即调用guard_noncombat；拒绝后停止该试验并保留证据。缺失字段不默认为0，不关闭AI或强制改角色来制造通过。

本轮只完成单元测试和对真实记录的离线重放。尚未接入正式桥或复跑新的实机移动验收；不能据此把旧失败记录改成通过。原始力量在无甲移动对照也会变化，不应对运行中的游戏直接套用暂停场景的全属性恒等断言；敏捷变化等未解释项目仍需记录与调查。
