# 私有外观快照研究源代码

这是为跨机审查复制的**自编研究源码**，不是模组发布包。不含游戏二进制、SDK头、模型、人物数据或存档。原文件 SHA-256 见 `source-manifest.json`。

该manifest保留首轮历史源码/DLL哈希，不表示当前修复版本。
当前修改与复测步骤见 [所有权修复交接](../../docs/handoffs/native-ownership-20261103.md)。
每轮 results.json 记录当前C/头文件/构建脚本的实际SHA-256；跨平台换行可能改变字节哈希。
新增测试覆盖名称和双副本别名、空分配、读者占用及异常后停止。

- `private_snapshot_complete.c` / `test_complete.c`：type 66、空实例树的有界完整内容复制，补充 active 标记和空引用名；在两个私有对象上制造并恢复反例。
- `private_release.c` / `test_release.c`：候选仅能删除其自行创建并验证的私有对象，没有接受任意待释放指针的接口。
- 完整复制候选已在真实引擎的两个固定测试角色上完成私有对象试验，人物源数据未改变；这不等于已接入生产穿脱/保存。
- 私有释放候选只完成显式启用断言的 Mock 和静态审查，**实机删除未执行**。不要把函数、DLL哈希或Mock输出视为真实回收证明。

完整源码仍含测试机专用输出路径、引擎构建哈希和 ABI 门禁，无法直接移植到另一台游戏机器。CI/分析机只能编译并运行下方 Mock，不得尝试调用实际引擎入口或生成发布DLL。生产资源上限与保存/所有权门禁没有解除。

## 无游戏的 Windows Mock

需要本机安装 Zig 0.13.0；不需要游戏或游戏 DLL：

```powershell
python experiments/private_snapshot/build_offline.py --compiler <zig.exe> --out <新的证据目录>
```

脚本仅编译独立的 `test_*.c` 可执行程序，显式 `-UNDEBUG`，先用带副作用的断言验证断言确实执行，再运行 Mock。输出目录必须不存在；失败结果保留，不能通过删除证据重跑“通过”。Linux 上的编译/运行未验证。该脚本不编译或安装实机DLL。

审查重点：源对象永不释放；成功的私有析构正常返回后才能减少保留计数；异常隔离不重试；槽可重用而ID/累计计数不重置；保存借用尚未接入，不能据此允许线上释放。所有真实修复仍需测试机核对具体 commit 后复测。
