# 原版箭矢工作台接入

用户反馈原版箭矢工作台没有模组弹药。此前只接了原版储具，制作仍在新增弹药台，不能将存放支持说成原版制作支持。

本补丁只为原版两个 functionality `96451-crafting.mod` / `97092-rebirth.mod` 各追加 Energy200/210 两条 `item crafts` 引用，输出存放上限50，与现有专台一致。后缀是游戏内部历史记录来源：已从四个官方数据文件解析并验证两个原版建筑的关联；不是依赖名为crafting的第三方模组。不复制或发布原版记录内容/资产。

保留当前26条内容，包含已经建好的500/510专台、原三台配方、储具与科技。原版箭矢台的速度仍按原版倍率1；专台仍2倍。不能为了加速这两条配方改原版整台倍率，从而连带加速所有箭矢。材料、弹药产量/堆叠/数值均不改变，不添加脚本或轮询。

本机构建（命令中的路径由测试机提供，输出目录必须不存在）：

```powershell
python experiments/vanilla_ammo/build_candidate_local.py --game-root <game.root> --reader <local-reader.py> --output <new-private-output>
```

构建器使用已有本机FCS读取器和已共享的作者编码函数；只提取定义，绝不执行旧构建器的安装/构建顶层代码。校验源SHA、原字节往返、候选回读、全部旧记录、完整加载序的稀疏合并与原版建筑关联。不安装、不启动游戏、不读写存档。公开仓库只含作者源码、合成测试和小摘要，`.mod`产物留本机。
