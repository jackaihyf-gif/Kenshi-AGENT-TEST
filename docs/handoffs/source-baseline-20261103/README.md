# 当前生产 Lua 的审查快照

分享自编源码，供分析机审查池引用、原外观保存、力量校准与灯光；不包含游戏资产、DLL、存档或密钥。四份Lua来自当前生产文件，复制时未修改运行目录；manifest记录原始字节及共享LF字节SHA。

移动灯调查另补两份runtime目录的关联C参考源码，并记录当前安装DLL哈希。尚未重新构建证明这些C源码与安装DLL逐字对应，不能仅据参考源码宣称已经监控到全部native写入。

这是有限源码快照，缺少其余生产脚本、原生组件和配置，不是可安装的模组包。不要直接部署，也不要把Lua引用释放视为native对象已析构。后续正式修复从独立分支提交，测试机核对完整commit后按原生门禁复测。
