本机原始驱动为 `PR2_WORKTREE/reports/pr2-7712d57/real_retest.py`，分为 `preflight / cold / rounds / cleanup`，原文及哈希留本机。其依赖固定夹具和私有路径，不作为可移植源码发布。实际接口与步骤如下，供后续实现者按同一前置条件复现：
